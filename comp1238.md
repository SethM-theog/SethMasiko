# COMP1238 Study Notes
## Week 1 - Information Storage Before Computers
- Before computers, people stored information through writing and physical records
- People used cuneiform, recorded information on clay tablets
- People used materials like clay, paper and papyrus
## Week 2 - Representing text and numbers in computers
- Computers represent text and numbers using binary digits(bits)
- ASCII and Unicode assign numeric codes to characters so computers can represent text
## Week 3 - Markup Languages
- Markup languages use tags or symbols to describe the structure and formatting of text
- HTML structures web pages using tags like <h1> for headings and <p> for paragraphs
- Markdown links follow the format [link text](URL)
## Week 4 - Keyboards and Editors
- There are modifier keys like Ctrl, Alt, and shift
- Keyboard shortcuts speed up tasks
- Text editors let you create and edit plain text files including code
## Week 5 - Command Line Interface
- The CLI lets you interact with a computer using commands typed in
- A shell interprets your commands and runs them
- Paths can be absolute or relative
